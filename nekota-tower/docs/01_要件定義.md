# 01 要件定義 — ねこ太と十二月の塔（年末クエスト）

作成日: 2026-11-06 / 状態: PR 2（クエスト 10 本＋1F ボス戦＋ノーマル ED）

## 1. 背景と目的

メンタリスト DaiGo「年末までに必ずやること TOP10」（Dラボ 2023-12-12）を元に、年末の 10 ミッションを**現実でこなしながら**進めるレトロ風 RPG。
ゲームは現実での実行を検証できない。だから「受注 → 準備 → 実行 → 報告」の **報告を儀式化** し、現実で手を動かして報告したときだけ大きく祝う。入力そのものは静かに記録する（調査レポート `reports/年末クエスト ゲーム作りの真髄.md` の結論）。

オーナーの決定（変更しない前提）：

- 題名「ねこ太と十二月の塔」、副題「年末クエスト」。架空携帯機 **NETTA BOY**（メーカー NETTA、ブランド ゲーム部）。画面に「Teams」「®」「™」を出さない。
- 主人公 **ねこ太**（ネッタタウン体験デモの猫。体 #CDBDEC、黄色いハチマキ、サーモンの寿司、一人称「ぼく」）。
- 塔全体をつなげた 1 枚マップを上下左右に歩く。10F → 1F。1F の扉は 3 クリアで開く。
- 1 ファイル HTML、通信なし、PC 前提（主に Edge）。3 スロット手動セーブ、未保存インターロック、暗号化 CSV「メモリーカード」（ひらがな呪文）。
- ED 3 種（ノーマル／トゥルー／バッド＋2 周目）、ドットフォント埋め込み、言い訳モンスター採用。
- 置き場所は Viniprj（public）。

## 2. 利用者と利用場面

| 利用者 | 場面 | 求めること |
|---|---|---|
| 作者と 10 人程度の知人 | 12 月の間、PC で毎日〜数日おきに開く | アカウント不要。開いてすぐ続きから。現実でやったことを 1 分で記録できる |
| 年明けに振り返る本人 | 1/1 以降に開く | 結果発表と、自分の書いたことが流れるスタッフロール |

## 3. 機能要件（PR 1 の範囲）

### F1 起動とタイトル
- 起動は「でんげん（任意キー）→ 肉球と NETTA → NETTA BOY ブランド → PAW CHECK / MEMORY 3 SLOT / MEMORY CARD / LICENSED BY NETTA GAME-BU」の約 4 秒。いつでも任意キーでスキップ。初回の操作で AudioContext を起こす。
- タイトル：ロゴ、難易度 ★×10、報酬「人生最高の余暇」、PUSH START BUTTON（点滅 600ms 周期）。メニューは はじめから／つづきから／メモリーカード／せってい。きろくがあれば初期カーソルは つづきから。
- 右下に `(C) 2026 NETTA GAME-BU`、左下に `NETTA BOY`。

### F2 はじめから
- なまえ入力（6 文字まで、IME 対応の実 input）→ 確認 → きろく 3 枠から選ぶ（使用中なら上書き確認）→ 即セーブ → プロローグ（としのせの長老）→ 10F。

### F3 塔
- 40 列 × 130 行のタイルマップ。1 階 13 行（上壁 1・床 11・下壁 1）。階段（2 列幅、左右交互）で連続して降りられる。x=2 のエレベーター扉に乗ると階を選べる（1F は 3 クリアまで とざされている）。
- 各階：依頼人 NPC 1 体、石碑（きろく）、花の鉢 2〜3、本棚・窓（調べると一言）。10F に長老、1F の奥の部屋に扉とボス（準備中）。
- HUD：階、のこり日数、体感日数（12 月のみ）、しるし n/10、未保存 `*`。
- カメラは追従。エレベーターは縦坑をパンして移動。クリックした場所へも歩ける。

### F4 会話
- データ駆動のスクリプト（text / choice / if / goto / set / call / sfx / wait / end）。下部 4 行の窓、名前、▼、文字送り速度（そくじ／ふつう／はやい／おそい）。`{name}` `{daysLeft}` `{marks}` を差し込む。
- 依頼人の頭上に `?`（受けられる）`!`（報告できる）`●`（クリア済み）。

### F5 クエスト（⑩〜① すべて実装）
- 状態：offered → accepted → doing → cleared。クリア条件は条件表（eval 不使用）。
- 画面はタブ 3 つ：**じゅんび**（いつ・どこで・どうやって・じゃまするもの＋リスト）、**じっこう**（項目ごとのコマンド／日次チェック）、**ほうこく**（条件とボーナスの一覧、教訓、長老に報告）。
- ⑩：捨てる物リスト（タグ：大きい／場所を取る／いつも目に入る／アプリ・サブスク／高かった／なし、「なぜ買った？」1 行）。コマンド「すてる」（確認あり、60 秒以内なら とりけす）。クリア＝1 つ捨てた＋教訓 1 行。ボーナス＝大きい物／3 つ以上。
- ⑨：やめたい候補（理由付き）。「年末限定で やめると 宣言する」→「きょうも やめた」（JST の日付キーで 1 日 1 回、遡及不可）、「おやすみのお守り」2 個（休んでも連続が切れない）。クリア＝宣言＋3 日連続＋理由。ボーナス＝12/31 まで継続。
- ⑧：「行かなくて良かった予定ランキング」をプライベートと仕事で各 3〜5 件（理由付き）、「この先 どんな関係を 歩みたいか」1 行、ひとつを「整理する」。クリア＝両ランキング 3 件以上＋1 件整理＋1 行。
- ⑦：挫折 TOP5（3 件以上）、頼る人・足りなかった知識・前回の教訓の 3 欄、ひとつを「再開した」。ボーナス＝「頼る人に 連絡した」。
- ⑥：やりたかったのに手を付けなかったこと TOP5（3 件以上、理由付き）、「てをつけた」。ボーナス＝3 つ以上。
- ⑤：変えたいこと 1 行、3 段階に小さくするリスト（ちょうど 3 件）、いちばん下だけ「宣言」できる。以後は ⑨ と同じ日次チェックとお守り。クリア＝3 段階＋宣言＋3 日連続。
- ④：来年もっと会いたい人 TOP10（3 件以上、話したいこと付き）、「連絡した」、「予定が 決まった」（日付入力）。クリア＝3 人に連絡＋1 件予定。日付は `1/20` や `2027-01-20` の形で入力し、きょうより前の月日は来年として解釈する。
- ③：行きたかった場所（だれと、付き）、「予定を 入れた」（日付入力）。クリア＝1 件。じっこうタブに「待つ時間：あと n 日」を表示する。
- ②：今年できたこと・いまの記録・ちょい上の目標の 3 欄、「挑戦した」で記録を追加（追加そのものが実行）。数値が読み取れて記録を超えたら NEW RECORD を表示（ボーナス）。
- ①：空白の予約 3 件、離れるもの 1 行、「10 分 なにもしない」（1F 奥の部屋のボス、またはクエスト画面から）。操作すると残り時間が最大 30 秒戻る（ボスが回復）。X で中断でき、失敗にはならない。クリア＝予約 3 件＋完走 1 回＋ふりかえり 1 行。
- 祝い方の序列：入力＝カチッ音、受注＝短いジングル、実行＝ヒットストップ 6 フレーム＋トースト、報告＝ファンファーレ＋ヒットストップ 20 フレーム＋画面揺れ＋通知（クエストクリア／しるし／花／ボーナス／称号）。
- 称号：0 たびびと／1 みならい／3 ぼうけんしゃ／5 ゆうしゃ／8 けんじゃ／10 人生最高の余暇。
- クリアした階の鉢に花が咲く（セーブに残る）。

### F6 時間
- 実時間。日付キーは常に日本時間（`Intl.DateTimeFormat` の `Asia/Tokyo`）。局面：〜11/30 ×1、12/1〜27 ×2、12/28〜31 ×7（HUD の体感表示だけに使う）、1/1 以降は次に きろく を開いたとき **けっか はっぴょう**。
- 日本の年末暦の小ネタを HUD 下に出す（12/12 今年の漢字、12/13 正月事始め、12/28、12/29、12/30、12/31）。
- 時計の疑い（保存時刻が未来、日付キーが逆行）があるときは日次チェックを止め、穏やかに知らせる。

### F7 セーブ
- 本体メモリ：`localStorage` キー `nekota-tower:v1:slot:{1,2,3}` / `:suspend` / `:settings`。レコード `{v, app, build, savedAt, seq, playMs, state}`。版の線形マイグレーション。未来の版は拒否。
- 手動セーブのみ（石碑・メニュー）。未保存時だけ `beforeunload`（文言はブラウザ既定）。タブが隠れたとき・`pagehide` で「ちゅうだんデータ」を書き、次の つづきから で一度だけ復帰を提案する（スロットには数えない）。
- ゲーム内「でんげんを きる」は自前の確認「セーブしてないけど とじますか？」。
- 本体メモリが使えない環境ではバナーで知らせ、メモリ内で動かし、カードへの書き出しを勧める。

### F8 メモリーカード
- JSON → deflate-raw → AES-GCM（埋め込み 256bit 鍵、IV 12B、AAD `nekota-tower/v1`）→ かな 64 字（紛らわしい対を除外、表は凍結）→ 40 字/行 → CSV `slot,line,data`（UTF-8 BOM）。
- 書き出しは Blob＋`<a download>` のみ。ファイル名 `nekota-tower_card_YYYYMMDD_slotN.csv`。読み込みは ファイル選択 と ドラッグ＆ドロップ。失敗はすべて「あいことばが ちがうようです」。
- 任意の あいことば（PBKDF2-HMAC-SHA256 600,000 回＋16B ソルト）。
- 暗号化は「読めなくする」ためのもの。鍵は HTML にあるので安全性の主張はしない（README に明記）。

### F9 設定
- もじの はやさ／こうかおん／テレビふう（CRT）／ひょうじ（ドット基準＝デバイスピクセル整数倍／ウィンドウ基準）／うごき（ひかえめ＝`prefers-reduced-motion` の既定値）。

### F10 エンディング
- けっか はっぴょう（1/1 以降）：しるし、称号、ひとこと。
- ノーマル ED：① をクリアしたあと長老に話すと「塔の 景色を 見る」が選べ、本人の入力（捨てた物、宣言、連絡した人、予定の日付、教訓、報告）が流れるスタッフロール。実行済み＝明、未実行＝暗。責めない。見たあとも塔に戻れる。
- トゥルー（10/10）／バッド（1/1 で 3 未満）／2 周目は PR 3。

## 4. 文言ルール（調査レポートより）

- 使わない：「ストレス25%減」「ツァイガルニク効果」「説明責任65/95%」。「注意力20%」は一研究の要約として弱める。×2／×7 は体感表示に留め、事実として語らない。
- 使わない：既存ゲームの逐語（ぼうけんのしょ／ふっかつのじゅもん／おきのどくですが／強くてニューゲーム）と既存ジングルの旋律。表記は「きろく」「あいことば」「つよくて 2しゅうめ」。
- ランキングと数値 XP を前面に出さない。ストリーク喪失の劇的演出をしない。称号は行為の言語化。

## 5. 非機能要件

- 1 ファイル `index.html`（PR 1 時点 約 430 KB）、外部参照なし、`file://` で動く（ES modules・fetch 不使用）。
- 内部解像度 320×240 を整数倍。Windows 125% / 150% でもドットが均一（デバイスピクセル基準）。横スクロールなし。
- キー配列に依存しない（`KeyboardEvent.code`）。IME 合成中はゲームのキーを無視。
- `prefers-reduced-motion` で CRT の帯・揺れを止める。点滅は毎秒 3 回以下。
- 公開リポジトリ：個人情報・社名・認証情報を含めない。
