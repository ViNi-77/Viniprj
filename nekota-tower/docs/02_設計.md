# 02 設計

## 1. 構成

```
src/
├── index.tpl.html     <!--@fonts--> <!--@css--> <!--@js--> {{BUILD}} のマーカー。CSP 付き
├── css/               screen（土台・整数倍）/ crt（走査線）/ overlay（入力欄・ドロップ）
├── fonts/             PixelMplus12-sub.woff2 / DotGothic16-sub.woff2 / subset.json / README.md
├── data/              text（文言）/ dialogs（会話）/ quests（定義）/ map（塔）/ entities（NPC）/ jingles（音）
├── svg/               nekota（4 方向×3 フレーム）/ npcs（長老・依頼人・ボス）
└── js/                00_ns 01_util 02_time 03_storage 04_codec 05_input 06_audio 07_screen 08_fonts 09_text 10_gfx
                       11_sprites 12_scenes 13_loop 14_state 15_settings 20_dialog 21_menu 22_inputbox
                       30_scene_boot 31_scene_title 32_scene_name 33_scene_slot
                       40_tilemap 41_camera 42_player 43_entities 44_scene_map
                       50_quests 51_quest_q10 52_quest_q9 53_scene_quest
                       60_scene_save 61_scene_card 70_scene_ending 80_interlock 99_main
```

- グローバルは `window.NT` ひとつ。各ファイルは IIFE で `NT.Xxx` を公開。依存は番号順のみ（後のファイルが前を使う）。data/ と svg/ はロジックを持たない。
- classic script のみ（`file://` では ES modules / fetch が使えない）。外部参照は build が拒否する。
- `scripts/build.py` が SOURCES 順に連結し `index.html` を生成。`{{BUILD}}` はソース全体の SHA-256 先頭 8 桁。`--check` で生成物の鮮度を検証、`--subset` でフォントを再生成、`--dev` で `dev.html`。

## 2. 実行時

- **ループ**（13）：rAF ＋ 16.67ms 固定ステップ（蓄積上限 5 フレーム）。`freeze(n)` でヒットストップ（上限 24）。`shake(px, ms)` は CSS transform（reduced-motion で無効）。隠れたら停止。
- **シーンスタック**（12）：`BOOT TITLE NAME SLOT MAP DIALOG MENU CONFIRM NOTICE QUEST CARD CARDMENU SETTINGS ENDING`。`{id, opaque, enter, exit, update, draw, resume}`。描画は最寄りの不透明シーンから上へ。`remove(scene)` で先頭でないシーンも閉じられる（会話から別画面を開いた直後に会話を閉じる）。
- **入力**（05）：`KeyboardEvent.code`。`ok: Z/Enter/Space`、`cancel: X/Esc/Backspace`、`menu: C/Tab`、十字 `Arrow*/WASD`、`dash: Shift`。`pressed`（エッジ）と `held`。IME 合成中（`isComposing || keyCode===229`）と input/textarea 上は無視。十字は 320ms 後に 90ms 間隔でリピート。クリックは内部座標に変換して `clicks()` に積む。
- **画面**（07）：320×240 の canvas。既定はデバイスピクセル基準の整数倍（CSS 幅 = 320N/dpr）。`--scale` を DOM オーバーレイと走査線の周期に共有。CRT は CSS オーバーレイ。
- **文字**（09）：canvas `fillText`。全角 12px / 半角 6px の固定ピッチ。自前の折り返しと禁則（行頭 `、。，．・：；？！ー）」』】〕〉》` と小書き仮名、行末 `（「『【〔〈《`、句読点ぶら下げ）。フォントは `"PM12","MS Gothic","Yu Gothic",monospace`（サブセット外の字はシステムフォントに落ちる）。
- **フォント**（08）：`@font-face` を data URI で埋め込み、`document.fonts.load` を 3 秒タイムアウト付きで待ってからタイトルへ。PixelMplus12（本文）、DotGothic16（見出し）。❶〜❿ は両フォントに無いので ①〜⑩ を使う。✓ も無いので ●／○。
- **日本語入力**（22）：canvas 上に実 `<input>/<textarea>` を重ねる。`compositionend` の直後 50ms の Enter は無視（Safari の順序対策）。Enter で確定、Shift+Enter で改行、Esc で取消。長さは `Intl.Segmenter` の書記素。
- **スプライト**（11, svg/）：SVG 文字列を data URI → Image → offscreen canvas に等倍でラスタライズ（32×40、ルート svg に width/height 必須）。ねこ太は 4 方向 × 揺れ 3 フレーム＋手を振る 1 枚、NPC 12 体。失敗時はプレースホルダ。
- **マップ**（data/map, 40〜44）：文字配列は `map.js` の生成関数が階ごとの設定から組み立てる。凡例 `# = . , S s E | M D d B W F @`。階ごとに 4 色パレットでタイルセットを起動時に手続き描画（画像ファイルなし）。衝突は凡例と NPC 位置。主人公はタイル単位移動（2px/フレーム、ダッシュ 4px）、クリック移動は BFS。カメラは追従＋クランプ、エレベーターは 700ms パン。
- **会話**（20, data/dialogs）：ステップ列を解釈。`if` 条件 `quest:<id>:<status>` `flag:<name>` `clears>=<n>` `phase:<name>` `impl:<id>` `reportable:<id>`。`call` はホワイトリスト（`quest.accept/open/report`, `scene.save`）。
- **クエスト**（50〜53, data/quests）：定義の `clear` / `bonus` は `[atom, op, value, label]`。atom は `doneCount doneTag lesson declared streak reason streakThrough`。連続日数は今日（または昨日）から遡り、お守りの日も数える。日次チェックは `Time.jstKey()` の当日のみ、`clockSuspect` 中は不可。
- **時間**（02）：`Time.now()` は `Date.now` をラップ（Playwright の `page.clock` で差し替え可）。局面 `prep/dec/final/over`。
- **保存**（03, 14, 60, 80）：`Storage` は probe → 失敗時メモリ内。`State.toRecord()` が `{v, app, build, savedAt, seq, playMs, state}`。`setDirty` の変化で `beforeunload` を付け外し。`visibilitychange: hidden` / `pagehide` で `:suspend`。
- **カード**（04, 61）：下記 3 節。
- **音**（06, data/jingles）：Web Audio のみ。矩形波（PeriodicWave で duty 12.5/25%）、三角波、15bit LFSR ノイズ。`play(name)` はジングル表 `[midi, t, dur, type, vol, slide]`。`startMusic(song)` は簡易ステップシーケンサ（ED）。
- **テスト窓口**（99）：`window.__NEKOTA`（state / scene / todayKey / skipBoot / endDialog / teleport / setClears / quests / inputbox …）。`?fast=1` で起動演出を飛ばす、`?nocrt=1` で CRT 無効。

## 3. メモリーカードの形式（凍結）

- バイト列：`"NKT1"(4) | flags(1: bit0=あいことば, bit1=deflate) | salt(16, bit0 のとき) | iv(12) | AES-GCM 暗号文＋タグ`。平文は UTF-8 JSON `{v:1, entries:[{slot, record}]}`。AAD は ASCII `nekota-tower/v1`。
- 鍵：埋め込み 256bit 定数（難読化に過ぎない）。あいことば時は PBKDF2-HMAC-SHA256 600,000 回。
- かな 64 字（6bit/字、末尾は 0 詰め、パディング文字なし）：
  基本 40 `あいうえお かきくけこ しすせそ たちつてと なにの はひふへ まみむめも やゆよ らりるれ をん`、
  濁点・半濁点 24 `がぎぐげご ざじずぜぞ だづでど ばびぶべぼ ぱぴぷぺぽ`。除外：ぬ(め) ね・わ(れ) ろ(る) ほ(は) さ(ち) ぢ(じ)。
  `KANA_HASH = 9ac27118c62c584b225393593656d1056701390dce4c3025f7ebd6e2e53b90e9`（表を変えるときは AAD の版も上げる）。
- CSV：BOM ＋ `slot,line,data`、data は 40 字/行、スロットごとに独立したブロブ。改行 `\n`/`\r\n` 両対応、空行無視。
- エラーは `format / auth / version / unsupported` の 4 種だが、画面の文言は常に「あいことばが ちがうようです」。

## 5. マップ

- 1 階の帯は 13 行。行 0 と 12 が壁、行 1 が `=`（壁の上面、本棚 `B`・窓 `W` を置く）、行 2〜11 が床。x=0 と 39 が壁、x=1 がエレベーター縦坑 `|`、x=2 の行 6 が扉 `E`。
- 下り階段は偶数階で x=36,37、奇数階で x=5,6（行 11〜12 と次の階の行 0〜2 を `S`/`s` で貫く）。
- 絨毯は x=17〜22、行 3〜10。石碑と鉢は `map.js` の `FLOORS_CFG`。1F は行 8 に内壁と扉 `D`、行 9〜11 が奥の部屋。10F の行 5 x=20 が開始位置。
- パレット：10F `#0b1a2e #1f3b57 #5c8bb0 #dbe9f5` → 1F `#2e1a0b #6e3b1f #d08a4f #fff1dc`（寒色から暖色へ）。
