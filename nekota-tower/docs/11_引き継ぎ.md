## 既知の制約

- 1F の扉は 3 クリアで開く。検証の近道は `window.__NEKOTA.setClears(3)`。「なにもしない」の長さは `?white=秒` で短縮できる。トゥルー ED は `setClears(10)` → 長老、スタッフロールは `window.__NEKOTA.skipRoll()` で飛ばせる。言い訳モンスターは `?excuse=1`／`?noexcuse=1`。
- `beforeunload` の文言は変えられない（ブラウザ既定）。ゲーム内の「でんげんを きる」だけ自前の文言。
- Firefox は file:// のファイルごとに localStorage が分かれる。カードが正本。
- 暗号化の鍵は HTML に埋め込み。読めなくするためのもので、秘密を守る仕組みではない。
