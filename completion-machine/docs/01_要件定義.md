# 01 要件定義 — 「補完機」（生成AIの中身を、動く機械で見せる研修教材）

作成日: 2026-10-24 / 状態: PoC

## 0. 仮説

- **課題仮説**: 生成AIの基礎研修で「AIは続きを埋める機械」「机の広さ」「指示の積みすぎ」「前提は疑わない」を口頭と静止画で説明しても、受講者には残らない。
- **解決仮説**: 受講者が自分の手で工程を1つずつ進め、机に紙が積まれて落ちるところまで見れば、仕組みが体に残る。

## 1. 背景と目的

研修の持ち帰る一言は「生成AIは、とても性能の良い補完機」。考える機械ではなく、届いた手紙の続きを一語ずつ埋める機械である。
この教材は、その「補完機」を本当に机の上の機械として描き、受講者がボタンで動かせるようにする。
目的は暗記ではなく、「渡すものが変われば答えも変わる」を体で分かってもらうこと。

## 2. 利用者と利用場面

| 利用者 | 場面 | 求めること |
|---|---|---|
| 研修の講師 | 講義の合間にブラウザで開き、工程を1つずつ押して見せる | 開いた瞬間に機械と分かる。操作はボタンだけ |
| 受講者（AI初心者を含む） | 研修後に自分で開いて触る | 押せるボタンが1つしかなく迷わない。一行ヒントで意味が分かる |
| 研修資料を作る人 | スライドや動画に貼る | 動画版（mp4）と静止画がある |

## 3. 機能要件

### F1 機械（静止）
- 机の上の「補完機」。投入口、綴じ器、机（天板と、端から落ちた紙の受け皿）、読み取りヘッド、候補ダイヤル、印字テープ、注意力メーター、ボールペン、片付けレバー。
- 部品は80〜150個。1倍で機械と分かり、4倍に拡大しても部品が見つかる。
- 明・暗の2テーマ。

### F2 ステップボタン（8工程）
| # | 工程 | 機械で起きること | 研修の対応 |
|---|---|---|---|
| 1 | 手紙を書く | 今回の頼み・材料・見本の紙が投入口に入る | 手紙の中身（今回の頼み／材料／見本） |
| 2 | 前のやり取りを綴じる | これまでのやり取りの束が同じ手紙に綴じられる | 毎回はじめまして。前の分を送り直している |
| 3 | 机に広げる | 手紙の紙が机に並ぶ。使用率が見える | 手紙の中身は5つ。前置きは最初から机にある |
| 4 | 次の一語を選ぶ | 候補ダイヤルが回り、一語がテープに印字される | 次に来る言葉を当てる |
| 5 | 続きを埋める | 同じことを繰り返して文になる | 当てたら、その次を当てる |
| 6 | 往復を重ねる | 往復ごとに束が増え、机があふれて最初の紙が落ちる | 壁①: 机の広さ |
| 7 | 条件を積む | 注意力メーターの針が条件数で割れ、1条件あたりの取り分が下がる | 壁②: 指示の積みすぎ |
| 8 | 机を片付ける | レバーで机が空になる | 話題が変わったら新しいチャット |

- 押せるのは次の工程だけ。完了した工程は薄く、次の工程は光る。
- 手動／自動の切替。自動は全工程を1周（約46秒）して止まる。選択はこの端末に記憶する。
- 「最初から」で工程1に戻る。
- キー操作: Space／Enter で次へ、Home で最初から。
- 各工程に一行ヒント（7歳児が一読で分かる言葉）と擬音。

### F3 数値の表示
- すべての数値は `js/model.js` の1つのモデルから出る。読み出し欄（カード右下）、机の使用率、取り分、語数。
- 数値には札を付ける: 「公開値」（公開資料にある値）と「例示値」（説明のための架空の量）。
- 「トークン」「確率分布」「上限トークン数」は画面に出さない。

### F4 ビッグアイデア
- 図の下に一文: 「考える機械ではなく、届いた手紙の続きを一語ずつ埋める機械」。

### F5 動画版
- `?render` で開くと時計が止まり、`window.seek(t)` で任意の時刻の画を描ける。
- `scripts/render_film.py --mp4` で全工程の自動再生を mp4 にする（約46秒）。

## 4. 非機能要件

| 項目 | 要件 |
|---|---|
| 配布 | 単体HTML。外部URLなし（SVG名前空間を除く）。`file://` でダブルクリックで開く |
| 表示 | 1093×614、1280×720、390×844 で横スクロールなし。文字・ボタンが切れない |
| 動き | 時間基準の補間。`prefers-reduced-motion` では自動を選べず、手動は即時に切り替わる |
| 操作 | キーボードだけで全工程を進められる。読み出しは `aria-live` |
| 検査 | `lines` が 0、`audit passed`、`ui_smoke.py` 合格、`render_film.py --check` 合格 |
| 機密 | 社名・人名・講座原文・認証情報を含めない（public 前提） |

## 5. 範囲外
BGM・ナレーション、英語化、他の機械の量産、サイト化、CI、研修本番での実測。
