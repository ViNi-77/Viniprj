## 3. 機械と工程の対応

| 部位 | 意味 | 動く工程 |
|---|---|---|
| 投入口（トレイと紙束） | 今回の頼み・材料・見本 | ① 紙束が現れる |
| 綴じ器（アーム） | 前のやり取りを同じ手紙に綴じる＝毎回はじめまして | ② アームが下りて束が増える |
| 机（天板と20枠） | 一度に見えるもの。机に載った紙だけが読まれる | ③ 枠に紙が並ぶ ⑥ 枠が埋まり、端から落ちる ⑧ 空になる |
| 落ちた紙の受け皿 | 机から押し出されたもの。もう読めない | ⑥ 紙が落ちる |
| 読み取りヘッド（門形レール上） | 机の紙を読む | ④⑤ 机の上を往復する |
| 候補ダイヤル | 次に来そうな語の候補 | ④⑤ 回って一語を指す |
| 印字テープ | 出力（答え） | ④ 一語 ⑤ 八語 |
| 注意力メーター | 条件1つあたりに向く注意 | ⑦ 針が下がり、条件ピンが立つ |
| ボールペン | 書いた前提は消せない | 常に机の前置きの枠にインク線 |
| 片付けレバー | 新しいチャット | ⑧ 倒れて机が空く |

## 5. 世界座標（単位は実物のおよそ px、z は上向き）

- 台板 `{x:-150,y:-95,w:300,d:190}`、厚さ12、脚5。
- 投入口 x≈−120, y≈0。綴じ器はその上。
- 机 `{x:-60,y:-45,w:120,d:90}` 天板 z 14、枠は 5×4（x方向5、y方向4）。受け皿は机の +y 側の下。
- 門形レール: 柱 x=−68 と x=+68, y=−55, 梁 z 70。ヘッド台車は梁上を x で動く。
- ダイヤル中心 (100, −20) 半径 16、テープ基台 (100, 20) から +y へ。
- メーター中心 (100, 60)。条件ピンはその左 x=70..86。
- ボールペンは机の手前 y=−70 に横置き。片付けレバーは (−100, 60)。
- カメラ: azimuth 42、elevation 30。`fitProjection` で幅 760×高さ 500 に収める。

## 7. 動き（`live.js`）

- 時計は1つ `clock.now()`。通常は rAF で進め、`?render` では `window.seek(t)` が時刻を置く。
- 補間は閉形式（`from + (to−from)·ease(u)`、落下は減衰正弦）。dt 積分はしない。
- 工程 n の完了時刻 `at[n]` を持つ。手動は押した時刻、自動はスケジュール。`view(t)` は `at` から各部品の位置を決める。
- 自動の尺（秒）: 導入 1.5 → ① 4 → ② 4 → ③ 4 → ④ 5 → ⑤ 7 → ⑥ 9 → ⑦ 5 → ⑧ 4 → 終端 2.5（計 46）。
- reduced-motion: 自動は選べない。手動は補間なしで即時。`?render` は無視する。
- キー: Space／Enter 次へ、Home 最初から。フォーカスは `.iso-stage` だけ。
