# 05 映像設計 — 自動再生 46 秒

同じ HTML を `?render` で開くと時計が止まり、`window.seek(t)` で時刻 t の画が描ける。`scripts/render_film.py --mp4` が 1 フレームずつ撮って ffmpeg で H.264 にする。
画は `#cm-app`（工程列＋カード＋ヒント＋ビッグアイデア）を切り抜く。1500×1320 の窓で撮ると 980×752 になる。

## 語り（結論 → 情景 → 放置 → 変化 → お願い）

1. 結論: AIは考える機械ではなく、届いた手紙の続きを一語ずつ埋める機械。
2. 情景: 最初に「ですます調で」と頼んだのに、途中からタメ口になった経験。
3. 放置: 仕組みを知らないと「AIが壊れた」「使えない」で終わる。
4. 変化: 机が有限で、紙が落ちると分かれば、「話題が変わったら新しいチャット」が自然にできる。
5. お願い: ボタンを自分で押して、落ちる瞬間を見てほしい。

## 絵コンテ（秒は `live.js` の SCHEDULE と一致させる）

| 秒 | 工程 | 画 | 擬音 |
|---|---|---|---|
| 0.0–1.5 | 導入 | 机が空の機械。前置きの紙 2 枚だけ | — |
| 1.5–5.5 | ① 手紙を書く | カーソルが①へ動いて押す。投入口に 7 枚が積まれる | カリカリ |
| 5.5–9.5 | ② 綴じる | 綴じ器のアームが下りて、束が 13 枚になる | ガチャン |
| 9.5–13.5 | ③ 机に広げる | 束が消え、机の枠に紙が順に並ぶ（75%） | パサッ |
| 13.5–18.5 | ④ 次の一語 | ヘッドが机を横切り、ダイヤルが一回転して「本日は」を指し、テープに印字 | カチッ |
| 18.5–25.5 | ⑤ 続きを埋める | ヘッドが往復し、8 語が順に印字される | カタカタカタ |
| 25.5–34.5 | ⑥ 往復を重ねる | 机が埋まり、21 枚目が奥の端から受け皿へ落ちる（100%・1 枚落ちた） | ヒラヒラ…ポトッ |
| 34.5–39.5 | ⑦ 条件を積む | 条件ピンが 5 本立ち、注意力の針が 100% → 20% へ下がる | ギギギ |
| 39.5–43.5 | ⑧ 片付ける | レバーが倒れ、机の紙とテープの語が消える。前置きだけ残る | ガラガラ、スッ |
| 43.5–46.0 | 終端 | 空の机で静止。ビッグアイデアの一文 | — |

## 作り方

```bash
python scripts/render_film.py --check                  # 決定論と JS エラー
python scripts/render_film.py --stills 3               # 3 秒ごとの静止画と一覧表（PIL があれば）
python scripts/render_film.py --mp4 scripts/out/film.mp4 --fps 30
python scripts/render_film.py --mp4 scripts/out/film-light.mp4 --light
```

## 範囲外
BGM、効果音、ナレーション。`--mp4` は無音。
