# archify — 正確な構造図

[tt-a1i/archify](https://github.com/tt-a1i/archify)（MIT、v3.2.0、commit `25cf370`、2026-10-19 確認）。リポジトリを読んだ結果で、動かしてはいない。

## 何をするスキルか

システムの構造を、操作できる HTML の図にする。図の中身は JSON で書き、Node 製のツールが検査してから出力する。ブラウザでの表示確認まで自動で行う。考え方は「見栄えより正確さ」で、書かれていない関係は描かない。

- 図の種類は 10 種類: 構成図、ワークフロー、シーケンス、データフロー、状態遷移、ER、クラス、ツリー、年表、ウォーターフォール。加えて、問いに 1 ページで答える「1 ページ解説」がある。
- 実際のソースコードを読ませると、図の各要素から**特定の commit に固定したソース**へ飛べるリンクが付く。説明の根拠を後から追える。
- 出力は単体 HTML、画像、SVG、動画（WebM）。拡大縮小、経路のハイライト、検索、動きがある。
- Mermaid を読み込める。

## 向いていること・向いていないこと

- 向いている: 既存システムの全体像を、根拠付きで引き継ぐ。PR レビューで「どこが変わるか」を構成図で見せる。設計判断を「結論 → 理由 → 図」の 1 枚にまとめる。
- 向いていない: 数値グラフやダッシュボード（対象外と明記されている）。スライドに貼るための見た目の調整。

## 入れるときの注意

- 導入: `npx skills add tt-a1i/archify -g`。Node 18 以上。
- 約 1,170 ファイルと重い。
- 出力時に新しい版の有無を確認する通信がある（自動で更新はしない）。
- ソースリンクは GitHub を指す。非公開リポジトリの図は、権限のない人にはリンクが開けない。社外に出す図ではリンクを付けない設定にする。
- 操作画面（ボタン等）に日本語版はない。図の中の文字は日本語でよい。
- README のスポンサー広告はスキル本体と関係ない。
