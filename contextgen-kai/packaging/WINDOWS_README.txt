contextgen 改 0.3.0 / Windows 11 64bit

【はじめに】
1. ZIPを任意のフォルダにすべて展開します。ZIPの中から直接起動しないでください。
2. ContextgenKai.exe をダブルクリックすると、ブラウザでアプリ画面が開きます。
3. 「資料フォルダを登録」またはファイル追加から、読み取りたい資料を登録します。
4. 詳しい使い方は contextgen改_操作マニュアル.html を開いてください。アプリ画面からも開けます。

Pythonのインストールや、初回のOCRダウンロードは不要です。
日本語・英語のOCRを含み、資料の読み取りはPC内で行います。
図や写真の意味を説明する機能ではないため、読み取り結果を確認・修正してから
必要な資料と指示文をCopilotへ渡してください。

【フォルダの中身】
ContextgenKai.exe                 アプリを起動するファイル
contextgen改_操作マニュアル.html    画像付きの操作マニュアル
最初にお読みください.txt           この案内
_internal                        動作に必要なファイルとマニュアル画像

この4点を一緒に保管してください。_internalの中身を移動・削除しないでください。

【終了と更新】
ブラウザだけを閉じても、アプリ本体は動き続けます。
アプリ画面の「終了」で本体を終了してから、ブラウザを閉じてください。

新しい版に更新するときは、定期更新を停止し、アプリ本体を終了してください。
新しいZIPを別のフォルダにすべて展開し、ContextgenKai.exe を起動します。
登録先・修正内容・履歴は通常 %LOCALAPPDATA%\ContextgenKai に保存されるため引き継げます。
配布フォルダの場所が変わった場合は、アプリで「アプリ終了後も実行」の予約を保存し直してください。

【定期更新とバックアップ】
「アプリ終了後も実行」は、利用者のログイン中に実行されます。
電源OFF・スリープ・ログアウト中には実行せず、次に実行可能になったときに1回分を実行します。
バックアップには原本資料が含まれません。原本は別に保管してください。
復元した予約は停止状態になるため、内容を確認してから再設定してください。

第三者コンポーネントの権利表示: _internal\THIRD_PARTY_LICENSES\
