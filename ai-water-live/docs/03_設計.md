## 描画の方針

- 粒はすべて GPU。頂点属性に (出発点, 制御点, 終点, 位相, 速さ) を持ち、`uTime` から位置を計算する。CPU は uniform を更新するだけ。
- 密度は `uDensity`（0..1）で、位相が密度より大きい粒を消す。前提が変わると `main.ts` が log スケールで密度を決める（トークン: 1e8 → 0、6e9 → 1。水: 100 L/秒 → 0、15,000 → 1）。
- 球の裏側の点は法線と視線の内積で薄くし、球体メッシュで隠す。
- 画面の空き領域（右パネルと上のティッカーを除いた部分）の中心に球が来るよう `camera.setViewOffset` で投影をずらす。回転の中心は球の中心のまま。
- pixelRatio は 1.5 で頭打ち。

## 状態と更新

- `state.assumptions` が変わる → ティッカーの静的部分を再描画、地球儀の密度を更新、「あなたのトークン」を再計算。
- 累計は `worldSince(elapsed)` で毎フレーム計算。単位は 5 分後の値で決め、以後は上がる方向にだけ変える。
- 「あなたのトークン」の地域は施設内 WUE に `wueFactor` を掛けるだけ（発電側は地域に依らない）。

## 受入ライン

- 1093×614 / 1280×720 / 390×844 で横スクロールなし。スマホでは地球儀を上 58dvh に固定し、パネルを下に縦積み。

## 第 3 案: あなたの水

```
~/.claude/projects/**/*.jsonl ──(usage だけ・差分読み)──▶ scripts/water_meter.py
                                                            ├─▶ ステータス行（--statusline、Claude Code が呼ぶ）
                                                            ├─▶ ~/.cache/ai-water/today.json
                                                            └─▶ scripts/serve.py の /api/me ──▶ src/ui/me.ts（5 秒ごと）
```

- **読むもの**: 各行の `message.usage`・`message.model`・`message.id`・`timestamp` だけ。`"usage"` を含まない行は JSON として解釈もしない。状態ファイルにも本文は残らない（単体テストで確認）。
- **差分読み**: ファイルごとのバイト位置・既出 ID（直近 5,000）・日別×級の集計を `~/.cache/ai-water/state.json`（Windows は `%LOCALAPPDATA%\ai-water`）に保存。書きかけの最終行は次回に回す。35 日より古い日は捨てる。書き込みは一時ファイル → `os.replace`。
- **ステータス行**: 1 行、表示幅 64 以内、2 回目以降 50 ms 前後。棒は「いま満たしている 500 mL ボトル」の水位。例外は握りつぶして「💧 計測できません（理由）」を出す（ステータス行で Claude Code を止めない）。
- **導入**: `scripts/install_statusline.py`。既存の設定をバックアップしてから `statusLine` を足す。別のステータス行があれば上書きしない（`--force`）。`--uninstall` で戻す。自分の設定入りのファイルはバックアップしない。
- **地球儀**: `src/globe/you.ts`（強調色の粒、`uOrigin` に地域、`uRate` に L/時 の log）。`faceHub()` でカメラを地域の正面へ。左下のカード `#me-card` の上端・ティッカーの下端・右パネルの左端から空き領域を求め、`setViewOffset` で球をその中心に置く。
- **静的配信**: `/api/me` が無ければ `meStatus = 'unavailable'` にし、カードと「実ログから」を隠して案内 `#me-hint` を出す。

## 第 4 段: ボトル画面と映像

```
src/bottle/profile.ts   第 1 案のボトル輪郭（SVG パス）→ 半径 × 高さ（m）。体積の積分表で「◯ mL → 水位の高さ」を出す（くびれ・肩でも正しい水位）
src/bottle/scene.ts     3D 舞台: ガラス（反射の強い薄い材質 + 縁のフレネル）、水（クリッピング平面で水位から上を切る）、
                        水面（円盤 + 頂点シェーダの波と着水の波紋 8 個）、注ぐ粒（InstancedMesh 90）、棚（InstancedMesh 最大 2,100）、
                        器の梯子（浴槽・プール・ドームを実寸で並べ、部分的に満ちた 1 個だけクリッピング）、カメラ（距離を log 補間、段ごとの見る角度）
src/ui/bottleView.ts    目盛り・大きな数字・出典チップ・7 日の日付ラベル（3D の位置に HTML を重ねる）・静的配信の「注ぐ」ボタン
src/film/main.ts        45 秒の映像。draw(f) がフレーム番号だけから絵を決める（第 1 案の作りを引き継ぐ）
```

- **ガラスに屈折（transmission）を使わない**: 内蔵 GPU で重く、半透明の水を透かせない（水が見えなくなった）。薄い反射ガラス + 縁のフレネルで十分にガラスに見える。
- **注ぐ速さは実時間**: 1 秒にボトル 1 本、差が大きいときは 3 秒以内に追いつく。フレームの経過時間を使うと、遅い GPU では注ぐのが遅れる。
- **実ログの取り直しで揺らさない**: 量が 1% 以上変わったときだけ器を作り直し、同じ段・同じ器ならカメラを動かさない。
- **空き領域**: 背の高い画面では下の表示の上、背の低い画面（ノート PC の 125%）では下の表示の右にボトルを立てる。投影を広げた全体の縦横比に合わせ、距離は「箱（器の段は箱を包む球）が空き領域に収まる」値。
- **ボトル画面は初めて開いたときに作る**（地球だけ見る人に余計な GPU を使わせない）。ループは表示中の画面だけ描く。
- **映像**: 数字はすべて `params.json`・`model.ts`・`example-usage.json`（作例・仮の数字）から計算（映像に数を直書きしない）。利用者本人の利用量は使わない。`scripts/render_film.py` が `dist/` を配って `?record=1` を開き、`canvas.toDataURL` で 1 枚ずつ取り出して ffmpeg に流す。
