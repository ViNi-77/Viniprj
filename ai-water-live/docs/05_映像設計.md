# 05 映像設計 — 「トークンの水」45 秒版（`film.html`）

第 1 案（`ai-water-footprint/film.html`）の作りを引き継ぐ。参考: [yihui-dev/awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos)
（秒単位の絵コンテ、フレーム番号だけで絵が決まる描画、毎フレーム動くカウンター、1 フレーム 1 粒、再生と録画の分離）。

## 仕様

- 1920×1080、60 fps、45.00 秒（2,700 フレーム）。Canvas 2D。外部資産なし。
- 数字はすべて `params.json` / `model.ts` / `example-usage.json`（作例・仮の数字）から計算する。映像の中に数を直書きしない。利用者本人の利用量は使わない（リポジトリが public のため）。
- 開き方: アプリ上部の「▶ 45 秒」、または `dist/film.html`。Space 再生/停止、← → 1 フレーム、Shift で 1 秒。

```bash
npm run build
python scripts/render_film.py --check          # 決定論と JS エラー
python scripts/render_film.py --stills 60      # 1 秒ごとの静止画と一覧表（scripts/out/film/sheet.png）
python scripts/render_film.py --mp4 scripts/out/film.mp4
```

## 台本（この語順のまま）

1. あなたの AI が、1 回応答する。
2. 電気になり、水になる。／1 回の応答で、500 mL ボトル ◯ 本。
3. 1 日、AI と仕事をすると。／「1 日に数十リットル」は、使い込めば届く桁。
4. 世界では、毎秒。
5. 器を大きくしていくと。
6. ただし、数字には幅がある。／トークンの水／あなたの今日は、Claude Code のステータス行に出せる。

## 絵コンテ

| 時刻 | 幕 | 画 |
|---|---|---|
| 0–5 s | 01 1 回の応答 | 作例の内訳（キャッシュ読み 30 万・書き 8,000・出力 2,500）が順に転がり、価格比の重み（× 0.1 / × 2 / × 5）を掛けて合計 5.9 万 加重トークンに |
| 5–13 s | 02 電力 → 水 | 式が 1 行ずつ組み上がる（× 3 Wh/1,000 = 176 Wh、× 4.875 L/kWh = 856 mL）。注がれる水で 1 本目が満ち、2 本目の 7 割まで |
| 13–21 s | 03 1 日の作業 | 1 フレームに 1 本ずつ、棚に 171 本（2.9 秒）。86 L。幅 0.79 L – 281 L、キャッシュ無しなら 469 L（作例・仮の数字） |
| 21–29 s | 04 世界 | 雨が濃くなり、10.2 億トークン/秒、4,974 L/秒に転がる。「1 日で 25 m プール 1,102 杯」の格子が 1 フレームに 1 杯 |
| 29–37 s | 05 器の梯子 | 同じ縮尺でボトル → 浴槽 → プール → 東京ドームへ引く（縮尺を log 補間、画面に収まらない器は追いつくまで出さない）。各段で「あの 1 日 = ◯」「世界の 1 日 = ◯」 |
| 37–45 s | 06 幅と結び | 低 / 中 / 高 の 3 本の棒（log）。水面が上がり題字。ステータス行の見本 |

## 検査（2026-10-22）

- `--check`: 9 フレームを 2 回描いて画素一致、JS エラーなし。
- `--stills 60` の一覧表を目視。器の梯子で次の器が巨大に映り込む問題と、小さすぎる比の指数表記を直した。
- `--mp4`: 1920×1080・60 fps・45 秒。
