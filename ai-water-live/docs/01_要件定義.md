# 01 要件定義 — トークンの水（第 2 案）

作成日: 2026-10-21

## 1. 背景

第 1 案（`ai-water-footprint/`）は「読むページ」で、評価は「見ていてつまらない」。最初の要約に戻ると、求められていたのは
**世界中で AI を動かすために消費されている電力と、その冷却で蒸発している水を、トークン単位でリアルタイムに見せること**。
「100 億トークン使った人はどれだけ水を無駄にしたか」が一目で分かること。HTML + CSS に縛らず「ちゃんとした Web アプリ」として作る。

## 2. 機能要件

| # | 要件 |
|---|---|
| F1 | 全画面の 3D 地球儀。代表的なデータセンター拠点 20 か所が脈打ち、トークンの流れが弧の粒で集まり、拠点から水の粒が立ち上って消える。自動回転とドラッグ。拠点にカーソルで名前・シェア・L/秒 |
| F2 | 世界ティッカー（トークン/秒、平均電力、蒸発する水/秒、開いてからの累計）を毎フレーム更新。累計は経過秒 × 毎秒の量で計算し、足し込まない。各タイルに 低–高 の幅と出典チップ |
| F3 | あなたのトークン: トークン数（プリセット 1 億 / 10 億 / 100 億 / 1 兆、「1 日あたり」切替）、モデルの級（軽量 / 標準 / 最上位 / 上限。例は 2026-10 時点）、地域 → 電力、施設内の水、発電側の水、合計、換算 3 つ、世界の何秒分か、共有カード PNG |
| F4 | 前提: 低 / 中 / 高 のプリセット + 4 本のスライダー。変えた瞬間に地球儀とティッカーが追従。localStorage にプリセットを記憶 |
| F5 | 方法: 計算の鎖、前提の表、拠点の表、出典の表を `model.ts` から描く。`methodology.html` にも同じ内容 |
| F6 | WebGL が無い環境では地球儀を消し、数字だけ動かす。`prefers-reduced-motion` では静止した地球儀と 1 秒ごとのティッカー |

## 3. 非機能要件

| 項目 | 要件 |
|---|---|
| 技術 | Vite + TypeScript + Three.js。UI は素の DOM。依存は npm でバンドル（CDN 不可） |
| 配布 | `npm run build` の `dist/` を `scripts/serve.py` / `start_windows.bat` で開く。GitHub Pages にそのまま置ける |
| 表示 | 1093×614（1366×768@125%）、1280×720（1920×1080@150%）、390×844 で横スクロールなし。数字は tabular |
| 性能 | 粒の位置は頂点シェーダが `uTime` から計算（CPU で粒を動かさない）。ドローコール 5 程度、2.5 万頂点未満。タブ非表示で停止 |
| 誠実さ | 出典 ID のない数字は画面に出さない。「推計」「仮定」を明記。単位は転がる途中で変えない |
| 機密 | 入力は保存しない（プリセットだけ localStorage）。public リポ前提 |

## 4. 受入条件

1. 開いて 2 秒以内に地球儀が回り、ティッカーの累計が増えている。
2. 100 億トークンを入れると、中の前提で約 4.9 万 L（浴槽 244 杯）と出る。
3. 前提を「高」にすると、地球儀の粒が増え、L/秒 が増える。
4. 共有カード PNG が保存できる。
5. 3 視口で横スクロールが出ない。

## 第 3 案「あなたの水」（2026-10-22 追加）

要約の核「自分が集中的に使うと 1 日に数十リットル蒸発しているかもしれない」を、試算ではなく**自分の実ログ**で確かめる。

| # | 要件 |
|---|---|
| F7 | Claude Code の利用記録（`~/.claude/projects/**/*.jsonl`）から、応答ごとの usage だけを読み、今日・7 日・直近の会話の水を出す。本文は読まない・保存しない・送らない |
| F8 | Claude Code のステータス行に常時「💧今日 ◯ L ▕ボトルの水位▏◯本 · 会話 ◯ L · 節水 ◯ L」を出す。ターンが終わるたびに増える |
| F9 | 地球儀に「あなた」: 左下の強調色カード（今日の L、ボトル、幅、世界の何秒分、7 日、キャッシュでの節水）と、自分の地域から立ち上る強調色の柱。開いた直後に自分の地域が正面に来る |
| F10 | 「あなたのトークン」に「実ログから（直近の会話 / 今日 / 7 日）」 |
| F11 | 静的配信（Pages / Artifact）では「あなた」を出さず、`serve.py` から開く案内を 1 行出す |

受入: 実ログから 1 日の水が出ること。最上位モデルを 1 日使い込む作例（仮の数字、`src/data/example-usage.json`）では中 約 86 L（幅 0.79 L – 281 L）で、「数十リットル」の桁になる。

## 第 4 段「ボトル」（2026-10-22 追加）

第 1 案（`ai-water-footprint/`）のペットボトルを 3D で作り直し、地球と切り替える画面として加える。

| # | 要件 |
|---|---|
| F12 | 上部の「地球 \| ボトル」で画面を切り替える。ティッカーと右パネルは共通 |
| F13 | 「いま」: 500 mL ボトル（3D のガラス）に、実ログの応答が増えるたびに水が注がれる。満ちたボトルは後ろの棚へ移り、新しいボトルが出る。静的配信では「応答 1 回ぶん注ぐ」（Space）で手で注ぐ（1 回 = 作例の 1 応答 約 0.86 L。仮の数字） |
| F14 | 縮尺の目盛り: いま / 7 日（1 日 1 段の棚）/ 1 年換算（今日 × 365）/ 世界の 1 日。量に合う器（浴槽・25 m プール・東京ドーム）を実寸で並べ、カメラが引く。ひとつ前の器を同じ縮尺で残す |
| F15 | 45 秒の映像版（`film.html`）を今の数字（トークン単位・実ログ）で作り直し、画面から「▶ 45 秒」で開ける |

受入: 作例の 1 応答で 500 mL ボトルが約 1.7 本満ちる（中の前提、最上位モデル）ことが目で分かる。
