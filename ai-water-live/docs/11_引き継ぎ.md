## 残っていること（優先順）

0. **ボトル画面の手触り**: 実機の GPU で、ガラスの質感・波紋・注ぐ粒の量を目で見て調整する（検査環境はソフトウェア描画で遅く、動きの確認が十分にできない）。
0. **映像の音**: 台本と秒は docs/05。ナレーションや BGM を当てるなら、絵コンテの秒に合わせる。

0. **他のツールの実ログ**: Codex CLI（`~/.codex/sessions`）や Gemini CLI のログ形式に対応すれば「AI 全部で今日何 L」になる。ChatGPT / Claude のブラウザ利用は、データのエクスポートを読み込む形が現実的。
0. **日別の壁**: `days`（直近 7 日）は集計済みなので、ボトルの壁（1 日 1 列）を地球儀の下に出せる。

1. **拠点の実在感**: いまは代表地点と仮定シェア。公表されているリージョン一覧（AWS / Azure / GCP）から拠点数で重み付けすれば根拠が増える。
2. **モデル級の鮮度**: 例示は 2026-10 時点（`MODELS_AS_OF`）。新モデルが出たら `model.ts` の `examples` と `MODELS` の時点を更新する。最上位 3.0 Wh は MR1 の四分位上に大型係数を掛けた置き値なので、公表値が出たら差し替える。
3. **ホバーのスマホ対応**: タップで拠点を選べるようにする（いまはカーソルのみ）。
4. **音**: 要望があれば、蒸発の粒に合わせた環境音。
5. **GitHub Pages**: workflow（`actions/upload-pages-artifact` + `deploy-pages`、`paths: ai-water-live/**`）を足せば公開 URL ができる。
6. **英語版**: 文言は各 UI モジュールに直書き。`strings.ts` に寄せてから切替を足す。

## 開発メモ

- `npm run data` で陸の点群を作り直せる（引数でサンプル数、既定 42,000 → 陸 12,037 点）。
- headless Chromium で WebGL を使うには `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`（`ui_smoke.py` が付けている）。
- `readPixels` は描画直後の同じタスク内でしか読めない（`Globe.readCenter()`）。
