# 見えない水 — 生成 AI が蒸発させる淡水を、器で見る

生成 AI を 1 回使うたびにデータセンターの冷却で蒸発する淡水を、ペットボトル・浴槽・プールで可視化する
1 ページのアプリ。ビルドなし、ライブラリなし、通信なし。

## 使い方

`index.html` をダブルクリックして開く。それだけ。

| 幕 | 何が見えるか |
|---|---|
| 01 いま、この瞬間 | 開いた瞬間から増え続ける世界累計（ChatGPT だけで 1 日 25 億回 × 1 回あたりの水）。画面下端の水面が実時間で上がる |
| 02 あなたの一回 | 「送信した」（Space / Enter）を押すたびに 500 mL ボトルへ一滴。満タンまでの残り回数、換算 |
| 03 積み上げると | 回数 × 人数 × 日数で、ボトル → 浴槽 → プール → 東京ドームへカメラが引く |
| 04 根拠 | 3 つの前提（低 0.26 mL / 中 45 mL / 高 519 mL）の出典と「何を含むか」 |

右上の 低 / 中 / 高 で前提を切り替えられる。選択と配色だけをこの端末の localStorage に記憶する。

### 映像版（`film.html`）

同じ内容を 45 秒の自動再生の映像にしたもの。1920×1080、60 fps、Canvas だけで描き、フレーム番号だけで絵が決まる。
`film.html` をダブルクリックすると再生が始まる（Space 停止、← → コマ送り）。MP4 にするには:

```bash
python scripts/render_film.py --mp4 scripts/out/film.mp4
```

絵コンテと、他のエージェントに渡せる指示文は `docs/05_映像設計.md`。

## 開発

```bash
python scripts/ui_smoke.py           # 画面版: 3 視口の検査とスクリーンショット
python scripts/render_film.py --check  # 映像版: 決定論と JS エラー
```

`playwright` の Python パッケージが要る（`pip install playwright`）。ブラウザは `$PLAYWRIGHT_BROWSERS_PATH` から探すので
`playwright install` は不要（この環境では実行しない）。

数値は `js/data.js` にだけ書き、出典は `docs/03_数値の根拠.md` と一致させる。設計は `docs/02_設計.md`。
