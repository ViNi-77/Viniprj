# 05 映像設計 — 「見えない水」45 秒版（`film.html`）

参考: [yihui-dev/awesome-opus5-5-videos](https://github.com/yihui-dev/awesome-opus5-5-videos)。
AI にアニメーションを **コードとして** 書かせ、1 つの HTML で動く映像にする手法の集まり。そこから借りたのは次の 5 点。

| 借りたこと | このファイルでの実装 |
|---|---|
| 秒単位の絵コンテと「この語順のまま」の台本 | 下の STORYBOARD と `T`（台本）定数 |
| フレーム番号だけで絵が決まる（時計・乱数を使わない） | `draw(f)` 1 本。疑似乱数は `hash(i, j)`。同じ f は何度描いても同じ画素（`render_film.py --check`） |
| 毎フレーム動くカウンター、1 フレームに 1 つ出る粒 | 幕 4 の累計、幕 5 の 25 億回と「1 日プール 288 杯」の格子（1 フレーム 1 杯） |
| 厳密なアートディレクション（色 3 系統 + 強調 1 色、質感） | 墨 `#0f1418` / 生成り `#f1ece2` / 水 `#4f9bd6`→`#2c6a9c` / テラコッタ `#e07a53`。粒状感とビネット |
| 再生・スクラブ・録画の分離 | `?record=1` で UI を消し `AWF.seek(f)` を公開。Playwright + ffmpeg で MP4 |

## 仕様

- 1920×1080、60 fps、45.00 秒（2700 フレーム）。Canvas 2D だけ。外部資産・通信なし。`file://` で開ける。
- 既定のシナリオは中（45 mL/回）。`?scenario=low|high` または画面下のボタンで切替可。絵コンテは中を基準に作ってあり、低では幕 2〜4 の水位がほぼ見えず、高では「…ほか N 本」が出る（それ自体が主張）。
- 音は利用者が「音 オン」を押したときだけ（着水の合成ドリップ）。録画には入れない。
- 操作: Space 再生/停止、← → 1 フレーム、Shift で 1 秒、R 最初から。

```bash
python scripts/render_film.py --check          # 決定論と JS エラー
python scripts/render_film.py --stills 60      # 1 秒ごとの静止画 + 一覧表（scripts/out/film/sheet.png）
python scripts/render_film.py --mp4 scripts/out/film.mp4 --fps 60   # 約 2.5 分、14 MB
```

取り込みは `canvas.toDataURL('image/jpeg', 0.95)`。`page.screenshot` の PNG は 1 枚 0.7 秒で 2,700 枚に 30 分かかるため使わない（静止画と決定論検査だけ無損失の PNG）。

## 台本（この語順のまま）

1. 質問を、ひとつ。（入力欄に「明日の会議のアジェンダを 3 行で」）
2. どこかで、水が蒸発する。
3. 1 日 20 回。
4. 10,000 人が、1 年。
5. ChatGPT だけで、1 日 2,500,000,000 回。
6. ただし、数字には幅がある。／何を含めて測るかで、桁が変わる。
7. 見えない水 ／ 生成 AI が蒸発させる淡水を、器で見る ／ index.html で、自分の 1 回を数える

## 中心の視覚ルール

**器は実寸比を守り、足りなければ数で見せる。** ボトルは 500 mL、プールは 25 m × 1.5 m。
縮尺で小さくなりすぎたものは消さず、ルーペで拡大して「この縮尺だとこの大きさ」と示す（幕 4）。
数字は常に単位固定で転がる（転がる途中で mL → L と単位が変わらない）。文言は語順ごと固定。

## 検査

- `--check`: 7 つのフレームを 2 回描いて画素一致、JS エラーなし。
- `--stills 60` の一覧表を目視: 文字の重なり、画面外へのはみ出し、場面間の位置の連続（幕 2 → 3 のボトルは x=1380 から群れの中心を保って移動）。
- 録画: `--mp4` が `libx264 / yuv420p` で書き出し、`ffprobe` で 1920×1080・60 fps・45 秒。
