# 02 設計 — 画面・状態・計算・見た目

## 1. 構成（ビルドなし、古典 script）

```
index.html          4 幕の文書構造とインライン SVG。末尾で js/ を依存順に読む
css/tokens.css      色・字・寸法の変数（light / dark）
css/layout.css      幕の骨格、タイポ、グリッド、横スクロール防止
css/scenes.css      器・液面・ボタン・数字・遷移
js/data.js          window.AW.DATA（シナリオ・器・換算・文言・出典）
js/format.js        AW.fmt（ja-JP 数値、単位、時間）
js/state.js         AW.state / AW.setState / 購読
js/loop.js          唯一の rAF ループ、visibility 制御
js/liquid.js        AW.Liquid: 波形 path 生成と液面の追従

js/scene-session.js 幕 2
```

`file://` で開く前提なので ES modules と `fetch` は使わない。`window.AW` 名前空間に集約する。

## 2. 状態

```js
AW.state = {
  scenarioId: 'mid',      // 'low' | 'mid' | 'high'
  t0: Date.now(),         // ページを開いた時刻
  litersOffset: 0,        // シナリオ切替で数字を連続させる補正
  session: { count: 0, startedAt: null, auto: false, autoEverySec: 30 },
  ladder: { perDay: 20, people: 1, days: 30 },
  reduced: matchMedia('(prefers-reduced-motion: reduce)').matches,
};
```

各幕は `render(state, now)` を公開し、波の位相・滴の配列など描画だけの一時値はモジュール内に閉じる。
`AW.setState(patch)` は浅いマージで、購読者に `(state, prev)` を渡す。

## 3. 計算式

| 量 | 式 |
|---|---|
| 単価 `u` [mL/回] | `DATA.scenarios[scenarioId].mlPerPrompt` |
| 世界の毎秒水量 `r` [L/s] | `DATA.world.promptsPerDay × u / 1000 / 86400` |
| 世界累計 [L] | `(now − t0) / 1000 × r + litersOffset` |
| 切替時の補正 | `litersOffset = 旧累計 − 新 r × (now − t0)/1000` |
| 自分の累計 [mL] | `session.count × u` |
| ボトル本数と残り | `floor(mL / 500)` と `mL mod 500` |
| 積み上げ [L] | `perDay × people × days × u / 1000` |
| 器の段 | `vessels` を容量昇順に見て、`L ≤ cap × 48` を満たす最初の器（超えたら次の段） |

既定シナリオで 1 日 25 億回 × 45 mL = 112,500 kL/日 ≒ 1,302 L/s。低なら 7.5 L/s、高なら 15,000 L/s。

## 4. 幕ごとの画面

### 幕 1 いま、この瞬間（100dvh）
- 左上: 小さな見出し「ChatGPT だけで、このページを開いてから」。中央: 巨大な数字（`clamp(3rem, 12vw, 9rem)`）と単位。下: 1 行の説明「1 日 25 億回 × 1 回 ◯ mL（出典）」。
- 右上: シナリオ切替（セグメント 3 つ）。直下に単価と出典を 1 行。
- 画面下端: 水面。`position: absolute; bottom: 0` の SVG。高さは累計量を `log` スケールで 0〜35dvh に写像（線形だと高シナリオで 10 秒で画面が埋まる）。
- 滴: 上から落ちる小さな円（上限 24）。レートに応じて頻度が変わる。reduced-motion では描かない。

### 幕 2 あなたの一回
- 2 カラム（スマホでは縦積み）。左: ボトル SVG（viewBox 0 0 200 520）。右: ボタンと数字。
- ボトル: 輪郭 path（stroke のみ）、内側シルエットの clipPath、その中の液体 path、上に半透明のハイライト帯、液面に薄い楕円（メニスカス）。
- 液面 y は目標値へ `lerp(0.08)`。送信直後は波の振幅を 3 倍にして 600 ms で戻す。
- 吹き出し → 滴 → 液面の順にアニメ（CSS keyframes で滴の落下、着水で `amp` を跳ねさせる）。
- 自動トグルは `setInterval` ではなく、rAF ループ内で `now − lastAutoAt ≥ autoEverySec×1000` を見る（タブ非表示中は進まない。復帰時に経過分をまとめて加算する）。

### 幕 3 積み上げると
- 上: スライダー 3 本と結果の数字（L と「◯個分」）。下: 器の舞台（1 つの SVG、viewBox を補間）。
- 器は実寸比で同じ座標系に配置（ボトル 高さ 1、2 L 1.5、ケース 2、浴槽 6、プール 100、ドーム 900 程度の相対寸）。
- 段が変わるとき `viewBox` の 4 値を 700 ms で easeInOutCubic 補間。線は `vector-effect="non-scaling-stroke"`。
- ラベルは HTML の重ね表示（rem）。SVG 内に文字を置かない。
- 現在の器に液体を満たし、足りなければ器を `<use>` で横に並べる（最大 48、超過は「…ほか ◯ 個」）。

### 幕 4 根拠
- 本文幅 `min(100%, 40rem)`。表はスマホで横スクロールさせず、`display: grid` で縦積みに落とす。

## 7. 数値の整形（`format.js`）

- `fmt.volume(mL)`: < 1,000 → `mL`（小数 1 桁、< 10 は 2 桁）、< 1,000,000 → `L`、< 10^9 → `kL`、以上 → `万 kL` / `億 kL`。
- `fmt.count(n)`: 1 万以上は `1.2万`、1 億以上は `3.4億`（`Intl` は万を出さないので手書き）。
- `fmt.duration(ms)`: `mm:ss`、1 時間以上は `h:mm:ss`。
