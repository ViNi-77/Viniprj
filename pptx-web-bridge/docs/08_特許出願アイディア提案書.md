# 特許出願アイディア提案書（草案）

基本設計基準書 1.3「知的財産・特許性の検知と積極提案規定」に基づき、本実装のうち新規性・進歩性の論点になり得る構造を列挙する。
権利は同 1.2 に従い株式会社アイシンに帰属する。出願可否の判断は知財部門に委ねる（先行技術調査は未実施）。

| # | 発明のポイント | 技術概要 | 新規性・進歩性の論点 | 業務上の効果 | 実装箇所 |
|---|---|---|---|---|---|
| 1 | 役割を図形名へ埋め込む往復同一性の保持 | 生成 PPTX の各図形名に `役割:要素ID` を書き、再読込時に役割（題名・副題・本文）と ID を復元する。テンプレート部品は予約名で除外する | PPTX の既存フィールドのみで、プレースホルダを使わずに意味情報を往復させる点 | PPTX ⇄ JSON ⇄ PPTX の往復で題名・目次・順序が崩れない | `pptx_generator.py`, `pptx_parser._role_from_name` |
| 2 | 文字量近似による決定的レイアウトと「（続き）」分割 | フォント計測なしに全角/半角の幅比で行数を推定し、収まらない本文を段落単位で次スライドへ送り題名に「（続き）」を付す。画像は残り高さに応じて縮小または送り | AI やレンダラーに依存せず、設定値のみで再現可能な分割規則 | HTML 長尺資料から枚数を自動決定でき、文字切れを前もって回避 | `layout.py`, `text_metrics.py` |
| 3 | 3 モード出力と未対応要素の画像切り出し | 編集性優先・見た目優先・ハイブリッドを同一 JSON から生成し、ハイブリッドでは未対応要素の領域のみをスライド画像から切り出して貼る | 要素単位で「編集可能なテキストシェイプ」と「画像化」を混在させ、位置は同一座標系で保証する点 | 編集性と再現性のトレードオフを利用者が資料単位で選べる | `pptx_generator._Gen.add_cropped_image` |
| 4 | 部品付きテンプレートの二重描画 | 表紙・中身・最終ページの部品（背景・ロゴ・帯・フッター）を 1 つの設定から Web（CSS）と PPTX（図形）の両方へ同じ座標で描く | 「テンプレート＝座標付き部品定義」として媒体非依存に持つ点 | 正式テンプレートを設定ファイルの差し替えだけで両媒体に反映 | `template_kit.py` |
| 5 | 要素判別レポートによる編集性の可視化 | 変換後の各要素を 文字/画像/図形/表 に分類し、座標・寸法・フォント pt・編集可否を一覧化して成果物へ同梱する | 「文字が画像化されていないこと」を利用者が数値で検証できる仕組み | 受入試験の証跡を自動生成 | `report.py` |

備考: 4 と 5 は一般的な設計の組合せである可能性が高く、1〜3 が主要候補。いずれも先行技術（PowerPoint のプレースホルダ、既存の HTML→PPTX 変換器）との差分整理が必要。
