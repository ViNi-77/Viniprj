# 変換マッピング仕様書（PPTX ⇄ Presentation JSON ⇄ HTML）

## 1. PPTX → JSON（`backend/app/pptx_parser.py`）
| PPTX | JSON | 備考 / フォールバック |
|---|---|---|
| タイトル・中央タイトル プレースホルダ | text, role=title | 図形名が `title:xxx` の場合も title（本アプリ生成 PPTX の再読込） |
| サブタイトル | text, role=subtitle | |
| 本文・オブジェクト プレースホルダ | text, role=body | `buNone` が無ければ箇条書き既定。`buAutoNum` は number |
| テキストボックス（塗り・枠線なし） | text, role=body | 上部 25% にある 20pt 以上の短文は title に推定 |
| 図形（矩形・角丸・楕円・三角・ひし形・右矢印・平行四辺形） | shape | 上記以外の図形は rect に近似し `SHAPE_APPROXIMATED` |
| 直線コネクタ | line | flipH/flipV を points に反映 |
| 画像 | image, fit=stretch | トリミングは無視し `IMAGE_CROP_IGNORED` |
| 表 | table | 結合セルは colspan/rowspan、列幅は pt。色・サイズ付きのセルは paragraphs も保持 |
| グループ | 子要素を平坦化 | chOff/chExt から親座標へ写像 |
| SmartArt | text（箇条書き） | データ部の文字列のみ。`SMARTART_TEXT_ONLY` |
| グラフ | unsupported | 枠＋題名。`CHART_UNSUPPORTED` |
| 動画・OLE・その他 | unsupported | 位置のみ。`ELEMENT_UNSUPPORTED` |
| フッター・日付・ページ番号、図形名 footer / page_number / confidential / logo / bar / cover_background | 出力しない | テンプレート側で再生成 |
| ノート | slide.notes | |
| 単色背景 | slide.background.color | グラデーション・画像背景は無視 |
| テーマ色（scheme color） | マスターの clrScheme + clrMap（スライド／レイアウトの clrMapOvr で上書き）で #RRGGBB に解決。lumMod/lumOff は brightness で近似 | 解決不能なら null + `THEME_COLOR_UNRESOLVED`（Issue #4） |
| テーマフォント（+mj-lt / +mn-ea 等） | fontScheme で実フォント名に解決 | ea → latin の順に採用 |
| run に無いサイズ・太字・色・フォント・箇条書き | 図形 lstStyle → レイアウトのプレースホルダ → マスターのプレースホルダ → マスター txStyles（title/body/other）の順で継承。normAutofit fontScale を乗算 | 取れない場合は役割既定値（Issue #5） |

## 2. JSON → HTML（`backend/app/web_renderer.py`）
| JSON | HTML | 備考 |
|---|---|---|
| slide | `<section class="slide">`（960×540px、transform で拡縮） | DOM 順は読み順（上→下、左→右） |

| shape | `<div class="el el-shape">`（background / border / border-radius） | 文字は中央寄せ（vertical_align に従う） |
| image | `<img>`（object-fit: contain / cover / fill） | Web 一式では `assets/` へ、プレビューでは data URI |
| line | `<svg><line>` | |
| table | `<table>`（colgroup 幅、th/td、colspan/rowspan） | |
| unsupported | 破線枠 + ラベル | |
| notes | `<aside class="notes">`（N キーで表示） | |
| テンプレート | 部品付き: 表紙背景画像・ロゴ・帯（clip-path で斜め）・フッター・ページ番号。旧式: フッター・ページ番号・機密表示 | `config/templates.json`, `template_kit.py`。座標は 960×540 基準で相対拡縮 |

## 3. HTML → JSON（`backend/app/html_parser.py`）
| HTML | JSON | 備考 |
|---|---|---|
| `<section>` / `<article>` / class に slide, page | 1 スライド | 無ければ h1/h2 で分割 |
| section 外の `<h1>` | 表紙スライド（title / subtitle） | 直後の `p.lead` を subtitle |
| h1-h3 | text, role=title | h4-h6 は太字本文 |
| p | text, role=body（class lead/subtitle/caption は caption） | strong/em/u/a/br をランへ |
| ul / ol（入れ子可） | text（bullet / number、level） | |
| img / figure+figcaption | image + caption | data URI と同梱ファイルのみ。外部 URL は `REMOTE_IMAGE_SKIPPED` |
| table（thead/th/colspan/rowspan） | table | th 行はヘッダー |
| blockquote | shape（surface 塗り、accent 枠） | |
| pre / code | text（等幅フォント指定） | |
| `.grid` / `.cards` / `.columns` / display:grid|flex の 2 個以上の子要素 | 子ごとに shape(role=card) + layout_hint{column, columns} | 最大 3 列（設定）。超過は折返し（`GRID_COLUMNS_LIMITED`） |
| `.card` 単体 | shape(role=card) | |
| header / footer / nav / script / style / form | 無視 | |
| 同梱 CSS の Computed Style（色・font-size・font-weight・text-align・カード背景/枠線） | h1–h6、p、li、figcaption、カード内文の run と shape に反映（`inherited` 印付き）。body と同じ色・サイズは既定として書かない。表セルは対象外 | Playwright で JavaScript 無効・offline・全通信遮断で描画（取込 HTML のスクリプトは実行しない）。無い環境は `COMPUTED_STYLE_UNAVAILABLE` 警告で静的解析のみ（Issue #6）。`html_import.use_computed_style` で無効化可 |

## 4. 自動レイアウト（`backend/app/layout.py`）
- 余白 36pt、間隔 18pt、題名高さ 64pt（設定）。
- 題名 → 本文の順に上から積む。`layout_hint.columns` を持つ連続要素は列に分ける。
- 画像は幅いっぱいを基準に、残り高さに収まらなければ縦横比を保って縮小し中央寄せ。残りが 35% 未満なら次ページ。
- 収まらない本文は段落単位で分割し、次スライドの題名に「（続き）」を付ける（`SLIDE_SPLIT`）。1 段落で収まらない場合は文の切れ目で分ける。表は行単位で分割し、ヘッダー行を続きにも付ける。
- 1 要素で 1 枚に収まらない場合は高さを切り詰めて `ELEMENT_TRUNCATED`。

## 5. JSON → PPTX（`backend/app/pptx_generator.py`）
| JSON | PPTX | 編集可 | 備考 |
|---|---|---|---|
| text | テキストボックス（word_wrap、bullet は pPr に buChar/buAutoNum） | ○ | 図形名 `role:id` |
| shape | 図形（塗り・枠線・角丸・楕円） | ○ | 濃色塗りの既定文字色は白 |
| image | 画像（contain は縦横比維持・中央寄せ、cover はトリミング） | ○ | |
| line | 直線コネクタ | ○ | |
| table | 表（列幅、結合、ヘッダー塗り） | ○ | |
| unsupported | editable/visual: 破線枠 + ラベル。hybrid: 画像化できれば画像 | △ | |
| 見た目優先 | スライド全体の PNG（2 倍解像度）+ 代替テキストに文字列 | × | Playwright 不可なら editable へ |
| テンプレート | 表紙背景（画像）、ロゴ（画像）、帯（平行四辺形）、フッター・ページ番号（テキスト）。図形名で識別 | ○ | 再読込時は除外 |

| スライド種別マーカー | 表紙・最終ページは `p:cSld@name = kind:cover / kind:closing` に記録し、再読込で復元（図形ではない） | — | Issue #8 |
| notes | ノート | ○ | |

## 6. フォント
- `config/font_fallback.json` の `aliases` で置換。Web は `web_font_stack`、PPTX は候補の先頭を指定。
- 実際の有無は表示側（ブラウザ / PowerPoint）で解決されるため、環境差はここで吸収する。
