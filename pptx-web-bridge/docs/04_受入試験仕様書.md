# 受入試験仕様書

`python scripts/loop.py` が全部を回す。1 つでも落ちたらコミットしない（`CLAUDE.md` 1 章）。

| 検査 | 中身 | 件数 |
|---|---|---|
| 単体・API（pytest） | `tests/` | 73 |
| 通し検査 E2E | `scripts/run_e2e.py`（結果は `docs/試験結果.md`） | 18 |
| 画面検査 | `scripts/ui_smoke.py`（Playwright。ノート PC 2 構成を含む） | 34 |

試験資料は実ファイル 1 つに合わせず、**壊れる軸を網羅した生成器**で作る（`CLAUDE.md` 9 章、`docs/99` 2026-09-13）。

- `samples/make_sample_pptx.py` — 6 枚の PowerPoint（題名・箇条書き・図形・表・画像・ノート）
- `samples/make_html_themes.py` — HTML 図解テーマ 6 種（素の CSS / インライン / CSS 変数 / 暗い配色 / 比較 / 外部 CSS）
- `samples/make_template_matrix.py` — 装飾の置き場所・ロゴ形式・枚数・比率を変えた PowerPoint 8 種
