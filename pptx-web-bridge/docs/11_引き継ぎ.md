## 4. 次に何かやるなら

優先度の高い順に、着手前に決めるべきこと付きで。

1. **実機確認 E22〜E24 を通す。** ここで出た不具合が最優先。特に E23・E24 は会社の実テンプレートでしか分からない（`samples/brand_template_ext.pptx` は模擬）。
2. **着せ替えの色対応の精度**（`restyle.build_color_map`）。多色の図解が多い資料で外れる。外れた実例が出てから直す。今は「2 回以上使われた色だけ触る」という保守的な規則で、外したら「元に戻す」がある。
3. **土台 PPTX の本文プレースホルダ流し込み**（`docs/07` #18）。題名だけは入るようになった。本文も入れると PowerPoint の「レイアウトのリセット」が効くが、座標を資料側で決める設計と衝突するので、どちらを取るかを決める必要がある。
