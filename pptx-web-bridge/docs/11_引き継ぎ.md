# 引き継ぎ（現在地と残り）

開発の約束ごとはリポジトリ直下の [`CLAUDE.md`](../../CLAUDE.md) を参照。

## 1. 現在地

| | |
|---|---|
| 版 | **0.6.0** |
| 何をするアプリか | PowerPoint / HTML 図解を読み取り、**Copilot に貼る指示文（プロンプト）を作る** |
| 何をしないか | 図解を描かない。PowerPoint も HTML も生成しない（作るのは Copilot） |
| 検査 | pytest 73 / 通し検査 18 / 画面検査 34 — **すべて合格** |
| 配布 | `dist/windows` ブランチに Windows 用 exe の ZIP（常に最新 1 件）。`build-windows` が `main` への push で自動更新する |

### 入っている機能（すべて Phase P）

| 機能 | 中身 |
|---|---|
| 中身を読み取る | PowerPoint / HTML 図解から、文章と構造を分けた「図解仕様」を作る |
| 型を直せる | 推定した型（フロー / カード / 比較 / 数値 / 年表…）と**判定理由**を出し、画面で変えられる |
| 見た目を読み取る | PowerPoint のテーマ色と、HTML 図解テーマの配色・フォント・角丸を取り出す |
| PowerPoint 化のプロンプト | HTML 図解 → Copilot in PowerPoint に貼る指示文 |
| HTML 図解化のプロンプト | PowerPoint → ふつうの Copilot チャットに貼る指示文 |
| 受け渡し一式 | プロンプト・図解仕様・Word 構成・画像を ZIP にまとめる |

### Phase P で消したもの

描画・レイアウト・テンプレート推定・着せ替え・差分マージ・品質検査（約 4,500 行）と、
キャンバス編集・テンプレート編集の画面。作るのが Copilot になったので出番が無くなった。

**救い出したもの**: 実ファイルのテーマ色を読む力（`pptx_styles.ThemeInfo` → `theme_from_pptx`）と、
図解の型の語彙（`diagrams.TYPES`）。どちらもプロンプトの材料として生きている。
