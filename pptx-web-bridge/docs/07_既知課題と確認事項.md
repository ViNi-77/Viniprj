# 既知課題と確認事項

## 既知課題（実装済み範囲の制約）
| # | 課題 | 影響 | 回避策 / 予定 |
|---|---|---|---|
| 1 | PPTX のテーマ色（scheme color）を解決しない | 解消（Issue #4: clrScheme + clrMap、brightness 近似） | lumMod/lumOff の HSL 厳密計算は未対応（近似） |
| 2 | プレースホルダ継承のフォントサイズを取らない | 解消（Issue #5: lstStyle → レイアウト → マスター txStyles を継承、fontScale 対応） | 段落レベル 9 超、行間（lnSpc）の継承は未対応 |
| 3 | 文字あふれ判定は近似 | 実フォントとの差で誤検知・見逃しがある | しきい値を `quality.*` で調整。PowerPoint 実機で実表示を確認 |
| 4 | 画像のグラデーション・拡張トリミング（負値）は非対応 | 元画像をそのまま配置 | 通常のトリミングは画像へ焼き込み（`IMAGE_CROP_BAKED`）、回転は `rotation_deg` で再現 |
| 5 | 見た目優先モードは Chromium 依存 | 未導入環境では編集性優先へ代替 | `start_windows.bat` / `start.sh` が導入を試みる。exe 版は OS 標準の Edge / Chrome を使う |
| 6 | CI 環境には LibreOffice Impress が無く、生成 PPTX の描画確認ができていない | 受入条件 5（PowerPoint で開き編集）は未確認 | Windows 実機で確認する |
| 7 | HTML の CSS（色・幅）は `style` 属性と限られた class 名しか見ない | 解消（Issue #6: 同梱 CSS を Computed Style で反映、外部通信は遮断） | 列幅（grid-template-columns）の反映は未対応（列数は子要素数から決める） |
| 8 | JSON に画像を base64 内包 | 画像が多いと JSON が大きい | 上限は `limits.max_upload_mb`。必要なら外部ファイル参照へ拡張 |
| 9 | プレビュー iframe が 720px 未満だと縦読みモードで開く | スライド表示にはボタン切替が要る | `web_export.flow_breakpoint_px` で調整可 |
| 10 | 4:3 資料へのテンプレートのフッター位置は 16:9 前提 | 端に寄る | キャンバス寸法から相対的に拡縮しているため大きく崩れはしない |
| 11 | コーポレートテンプレートのロゴ・表紙背景は参考画像から作った暫定素材（低解像度・近似） | 印刷時に粗い | `config/template_assets/` を正式素材へ同名で差し替える（ロゴ: 縦積み青/白、横並び青、表紙背景 JPG） |
| 12 | 画像内に焼き込まれた文字は文字化しない | 写真化された図の文字は編集できない | OCR / Vision AI（基準書 4.1）を将来の差し込み点とする。現状は画像として位置を保持 |
| 13 | 最終ページ（closing）は再読込時に通常スライドとして読まれる | 解消（Issue #8: cSld name に種別マーカーを残し復元） | — |
| 14 | 模擬 PPTX のプレビュー PDF は変換アプリの描画 | PowerPoint の実表示と差が出る | 実機確認は不要と判断（Issue #3 クローズ） |
| 15 | 表セル内の文字あふれは検査しない | セルの文字が切れても警告が出ない | 行高が動的なため誤検知が多く未実装。`docs/10_デバッグ所見.md` |
| 16 | テンプレート推定は規則ベース（形状・位置・プレースホルダ種別。Phase I で帯は「細長く端に寄る」形で判定し、色見本・装飾は部品にしない） | 端に無いロゴや文字入りの帯は装飾・文字候補になることがある | 「PPTX からテンプレート作成」画面の表で役割を変える（装飾 → 帯、文字候補 → フッター等）。グラデーション背景は先頭色の単色で近似 |
| 17 | 土台 PPTX（`use_base_pptx`）は python-pptx の内部（`_sldIdLst`, `drop_rel`）に依存し、外したスライドのメディアが残ることがある | ファイルが少し大きい。PowerPoint は問題なく開ける | 既定は従来の新規 PPTX。資料とテンプレートの寸法が違うと `BASE_PPTX_SIZE_MISMATCH` を出し、マスターの部品がずれる |
| 18 | 土台 PPTX の本文はプレースホルダに入れない（テキストボックス） | PowerPoint の「レイアウトのリセット」は効かない | 座標・サイズは資料側で決めるため。将来: 題名/本文プレースホルダへの流し込み |
