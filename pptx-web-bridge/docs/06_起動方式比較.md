# 起動方式の比較と採用案

企画書 6.1「起動方式の比較と採用案提示」への回答。想定利用者は Windows PC の社内メンバー。

| 方式 | 手順 | 利点 | 欠点 | 適用時期 |
|---|---|---|---|---|
| **A. exe 版 ZIP（PyInstaller、採用）** | GitHub Actions `build-windows` が作る ZIP を展開し `pptx-web-bridge.exe` をダブルクリック | Python 不要。解凍するだけ。黒い窓が開きブラウザが自動で立ち上がる | SmartScreen 警告を消すには署名が必要 | 試用者向け（今） |
| **B. バッチ起動（採用）** | `start_windows.bat`（仮想環境作成・依存導入・ブラウザ起動を自動化） | 追加ツール不要。更新は `git pull` のみ。デバッグが容易 | Python 3.10 以上と初回のネットワークが必要 | 開発者向け（今） |
| C. shell 起動 | `./start.sh`（B と同じ手順を bash で行う） | Linux / WSL でも同じ手順 | Windows 標準環境では使わない | CI・Linux 環境 |
| D. Docker | `docker compose up` | 環境差を吸収 | Docker Desktop が必要。非エンジニア向けではない | 社内 Web 移行の検証用 |
| E. 社内 Web 公開 | FastAPI をサーバへ配置、認証を前段に置く | 配布不要。共同利用 | 認証・保存先・ログの設計が必要（企画書の初期非目標） | 次フェーズ |

## Windows での起動の詳細
- `start_windows.bat`: PowerShell の `Activate.ps1` は実行ポリシーで拒否されることがあるため使わず、`.venv\Scripts\python.exe` を直接呼ぶ。`PYTHONUTF8=1` と `chcp 65001` でコンソールの文字化けを防ぐ。`py` ランチャー → `python` → `python3` の順で 3.10 以上を探す。
- exe 版: 凍結時の資源解決は `backend/app/config.py` の `resource_path`（exe の隣 → 同梱 の順）、起動は `backend/launcher.py`（ポート自動選択、準備完了後にブラウザを開く）。起動に失敗した場合は画面に原因を表示し `logs/startup_error.log` に残す。
- 展開先は `C:\pptx-web-bridge` のような短いパスを推奨（深い階層では Windows のパス長上限に達することがある）。

## 採用案
- 試用者向け: **A**（exe 版 ZIP）。
- 開発者向け: **B**（`start_windows.bat`）。`config/app_config.json` の `server.*` でポート・自動オープンを変更できる。
- 移行を妨げない設計: UI は静的ファイル、API は REST、状態は JSON ファイル。E へ移すときは保存先を `paths.*` で切り替え、前段に認証を置くだけでよい。
- A を選ぶ場合の注意: アプリ本体はブラウザを使わない（解析もプロンプト生成もブラウザ不要）。Playwright が要るのは開発時の画面検査だけなので、exe には同梱しない。

## 検証項目（Windows 実機）
1. exe 版 ZIP を展開し、ダブルクリックで起動してブラウザが開くこと（CI の起動スモークテストでは確認済み）。
2. `start_windows.bat` が `py` ランチャー無し／有りの両方で通ること。
3. 出来たプロンプトを実際の Copilot に貼り、指示どおりの結果が得られること（`docs/04` 7 章 E1・E2）。
4. 一式 ZIP の `構成.docx` が Copilot in PowerPoint の「ファイルから作成」で読めること。

## Mac / Linux で動かす場合
開発者が Mac や Linux を使う場合は **C（`./start.sh`）** をそのまま使える（中身は `start_windows.bat` と同じ手順を bash で行う）。Windows 前提の採用案は変えない。

- python3 は Homebrew（`brew install python@3.12`）などで 3.10 以上を入れる。python-pptx / lxml / Pillow は Apple Silicon・Intel とも wheel がある。
- 画面検査（`scripts/ui_smoke.py`）を回すなら `python -m playwright install chromium`。アプリ本体はブラウザを使わないので、入れなくても動く。
- exe 版（PyInstaller）は Windows 用のみ。Mac 用が要るときは同じ spec で Intel / Apple Silicon を別々にビルドする必要がある。
