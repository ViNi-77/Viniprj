# 専用要件定義書（草案・企画書から起こしたもの）

> 企画書 5 章「必須3」に相当する。正式な要件定義書が届いた時点で差分レビューする。

## 1. 目的と利用者
- 目的: PowerPoint（PPTX）と Web図解（HTML 一式）を共通の Presentation JSON で接続し、双方へ変換する。
- 利用者: 非エンジニアの資料作成者。ブラウザ操作のみで投入・プレビュー・出力を完結させる。
- 実行環境: Windows 上のローカル Web アプリ（ブラウザ UI + ローカル API）。将来の社内 Web 公開へ移行できる構造。

## 2. 画面（ブラウザ UI）
| 領域 | 機能 |
|---|---|
| 1. ファイル投入 | D&D またはファイル選択で PPTX / HTML / ZIP（HTML+CSS+画像） / JSON を投入。テンプレート選択（プレーン / コーポレート標準 / Generic Corporate Blue）。空の資料作成、最終ページ追加 |
| 2. 保存・復元 | プロジェクト名で Presentation JSON を保存・一覧・復元・削除（`projects/`）。ブラウザの LocalStorage に作業中内容を補助保存 |
| 3. 出力 | PPTX 出力モード（編集性優先／見た目優先／ハイブリッド）選択、Web 一式（ZIP）、PPTX、JSON のダウンロード。`output/` への書き出しも選択可 |
| スライド一覧 | 題名編集、順序変更（↑↓）、複製、削除、再レイアウト、品質検査 |
| 要素の編集 | 文字（1 行 = 1 段落）、表（タブ区切り）、画像の代替テキスト、ノート |
| プレビュー | Web図解ビューアをそのまま表示（ページ送り、目次、全画面、縦読み、ノート、印刷） |
| 警告 / 品質検査 / 要素一覧 / JSON / ログ | 変換警告、検査結果、要素判別レポート（文字/画像、x,y,w,h pt、フォント pt、編集可）、JSON 直接編集（検証・修復付き）、操作ログ |
| 進捗・デバッグ | 大ステップ + 累積％の進捗バー、ログレベル切替、`window.qcDebug` コンソールコマンド |

## 3. ワークフロー
1. PPTX → JSON → Web: 投入 → 解析 → プレビュー → 編集 → Web 一式出力
2. HTML → JSON → PPTX: 投入 → 解析 → 自動レイアウト → プレビュー → 編集 → PPTX 出力
3. JSON 保存 → 再読込 → 続きから編集 → 出力

## 4. 入力
| 形式 | 条件 |
|---|---|
| PPTX | 16:9 を主対象。4:3 も読み込み警告。上限 50MB（設定） |
| HTML | 単体 HTML、または HTML + CSS + 画像を含む ZIP。外部 URL の画像は取得しない |
| JSON | Presentation JSON v1.x。壊れていれば自動修復して警告 |

## 5. 出力
| 形式 | 内容 |
|---|---|
| Web 一式 | `web/index.html`, `viewer.css`, `viewer.js`, `presentation.json`, `assets/*`。外部依存なし、file:// で動作 |
| PPTX | 16:9（元資料の比率を保持）。3 モード。ノート・フッター・ページ番号・機密表示（テンプレート設定） |
| JSON | Presentation JSON（画像は base64 内包） |

## 5.1 文字の扱い（必須要件）
- PPTX / HTML 上でテキストとして存在する文字は、出力先でも必ずテキストシェイプ（編集可能）として出力し、フォントサイズ（pt）と座標・寸法（x, y, w, h: pt）を Presentation JSON に数値で持つ。画像化するのは「見た目優先」モードを明示的に選んだ場合のみで、その場合も代替テキストに文字列を残す。
- 画像とテキストの判別は要素種別（type）で行い、要素判別レポートで一覧・検証できる。

## 6. 変換ルール（要約。詳細は `03_変換マッピング仕様書.md`）
- 座標は pt、原点は左上。Web は 1pt=1px で描き画面に合わせて拡縮。
- HTML 由来の要素は座標を持たず、決定的な自動レイアウトが座標を付ける。1 枚に収まらなければ「（続き）」で分割。
- 未対応要素はエラー停止せず、位置を残した枠 + 警告 + 代替処理。

## 7. エラー・警告
- 取込失敗は HTTP 4xx/5xx と日本語メッセージ（工程名付き）。
- 変換警告は `{stage, code, message, slide_id, element_id, fallback}` で UI と JSON に残す。
- ログは `logs/app.log`（ローテーション）とコンソール。

## 8. 非機能
- ローカル処理のみ。外部送信なし。
- 実データ・固有名詞をソースコードへ固定しない（設定ファイルとサンプルのみ）。
- 起動: `start_windows.bat`（Linux は `./start.sh`）。Python 3.10 以上。exe 版は Python 不要。
- 試験: `python -m pytest`（単体・API）、`python scripts/run_e2e.py`（往復 E2E）。
