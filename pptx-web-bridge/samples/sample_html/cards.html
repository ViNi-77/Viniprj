3 つの出力モード（カード型サンプル）

PPTX 出力は用途に応じて 3 モードから選ぶ

モード比較

編集性優先

すべての要素をネイティブの図形・テキスト・表として出力する。

  • 後から自由に編集できる
  • 見た目は Web と多少異なる

見た目優先

Web 表示をそのまま画像化して貼り付ける。

  • 見た目の再現性が高い
  • 文字の編集はできない

ハイブリッド

テキストと表は編集可能にし、複雑な図は画像として貼る。

  • 編集性と再現性の折衷
  • 既定の推奨モード

選び方の目安

用途推奨モード
会議後に内容を修正する編集性優先
配布のみで修正しない見た目優先
迷ったときハイブリッド
